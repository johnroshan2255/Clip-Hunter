# Your sound effects

Put your own sound effects here (mp3, wav, ogg, m4a, aac, flac, opus) or add them in the app
(Settings → Sound effects library). The file name becomes the effect name, e.g. `vine-boom.mp3` → "vine-boom".
The AI director can then use them in clips.

Optional: `sounds.json` with descriptions helps the AI pick the right sound:

```json
{ "vine-boom": "dramatic meme boom — funny reveals", "bruh": "disappointed bruh — fails" }
```

Only add sounds you have the rights to use. Files in this folder are not committed to git.
